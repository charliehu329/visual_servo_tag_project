## 1. 适用对象与坐标约定

- 相机：当前实验中的**相机0**；
- 图像分辨率：`1920 × 1080`；
- 标称采集帧率：`60 fps`；
- 相机自动对焦：关闭；
- 标定时请求曝光：`-7`，设备读回值为 `-5`；
- 标定距离：棋盘距镜头约 `1.0 m`；
- `ZPOS`：变焦电机从机械回零位置起的绝对步数；
- `FPOS`：对焦电机从机械回零位置起的绝对步数；
- 图像坐标：OpenCV约定，原点位于左上角，`u` 向右、`v` 向下；
- 内参矩阵：

```text
    ┌ fₓ   0   cₓ ┐
K = │ 0    fᵧ  cᵧ │
    └ 0    0    1 ┘
```

- 畸变模型：OpenCV五参数模型，参数顺序必须保持为：

```text
D = [k₁, k₂, p₁, p₂, k₃]
```

| 参数 | 含义 | 作用 | 单位 |
|---|---|---|---|
| `fₓ` | 水平方向像素焦距 | 将归一化相机坐标换算为图像横坐标 | px |
| `fᵧ` | 竖直方向像素焦距 | 将归一化相机坐标换算为图像纵坐标 | px |
| `cₓ` | 主点横坐标 | 表示光轴与图像平面的横向交点 | px |
| `cᵧ` | 主点纵坐标 | 表示光轴与图像平面的纵向交点 | px |
| `k₁,k₂,k₃` | 径向畸变系数 | 修正桶形或枕形畸变 | 无量纲 |
| `p₁,p₂` | 切向畸变系数 | 修正镜头与成像面不平行造成的偏斜 | 无量纲 |

注意：`fₓ、fᵧ、cₓ、cᵧ`的单位均为**像素**，不是毫米。

## 5. 已验证的ZPOS到像素焦距模型

七个主档位 `Z=0,400,...,2400` 用于拟合，`Z=2200`未参与拟合，作为独立验证点。

为改善数值条件，先定义归一化变量：

```text
x = ZPOS / 400
```

三次拟合为：

```text
fₓ(x) = 7.58909330x³ + 4.34166606x² + 302.12056454x + 2045.82366420

fᵧ(x) = 7.66678115x³ + 3.75303317x² + 303.42085391x + 2042.61011695
```

模型只允许在以下范围内使用，禁止外推：

```text
0 ≤ ZPOS ≤ 2400
```

### 5.1 拟合与独立验证

| 项目 | fₓ | fᵧ |
|---|---:|---:|
| 七点拟合RMSE | 13.438 px | 13.124 px |
| 七点最大绝对残差 | 27.230 px | 26.858 px |
| `Z=2200`预测 | 5101.458 px | 5100.515 px |
| `Z=2200`实测 | 5143.324 px | 5139.261 px |
| 独立验证相对误差 | 0.821% | 0.760% |

因此，当前三次模型已经通过独立中间点验证，可供控制器在约`1.0 m`、相应最佳对焦状态下计算 `fₓ、fᵧ`。

## 6. 约1.0 m时的最佳对焦位置模型

同样令：

```text
x = ZPOS / 400
```

则七个主档位的最佳对焦位置二次拟合为

```text
FPOS₁.₀ₘ(x) = 7.55952381x² + 87.32142857x + 1186.90476190
```

模型在七个主档位上的：

- RMSE：`8.797 steps`；
- 最大绝对残差：`13.214 steps`。

在独立验证点 `Z=2200`：

- 预测：`1895.848 steps`；
- 实测：`1895 steps`；
- 误差：`-0.848 step`。

控制器发送电机整数步数时可对计算结果四舍五入。该公式**只适用于约1.0 m目标距离**，不能直接当作`0.8–1.3 m`全工作范围的对焦公式。

## 7. 控制器当前应如何使用

### 7.1 在已标定的离散ZPOS上

优先直接查本文件第3节对应的 `K、D、FPOS`，不需要插值。

### 7.2 在两个已标定ZPOS之间

- `fₓ、fᵧ`：使用第5节三次模型；
- `FPOS`：目标距离约`1.0 m`时使用第6节二次模型；
- `cₓ、cᵧ、D`：现阶段不建议使用全范围普通多项式拟合；
- 如果控制器必须立即支持任意ZPOS，主点和畸变可暂取最近标定档位的数据，并明确标注为临时方案；正式方案应等待剩余距离标定和高倍端复核后确定。

### 7.3 图像缩放或裁剪

本文件参数只对应原始`1920 × 1080`图像。

若图像分别按 `sₓ、sᵧ` 缩放：

```text
f'ₓ = sₓ × fₓ        c'ₓ = sₓ × cₓ
f'ᵧ = sᵧ × fᵧ        c'ᵧ = sᵧ × cᵧ
```

五个畸变系数不因单纯图像缩放而改变。

若先裁剪，裁剪窗口左上角为 `(u₀, v₀)`，则：

```text
c'ₓ = cₓ - u₀        c'ᵧ = cᵧ - v₀
```

若裁剪后还缩放，应先修正主点，再按缩放比例缩放 `fₓ、fᵧ、cₓ、cᵧ`。

## 8. 暂未完成，控制器不能假定已有的数据

当前系统工作距离已经确定为：

```text
0.8 m ≤ d ≤ 1.3 m
```

```text
F* = F(Z, 1.0 m)
K  = K(Z, F*(Z, 1.0 m))
```

2. `1.3 m`下相同七档；

4. 建立并验证二维关系 `FPOS = F(Z,d)`；
5. 判断内参是否需要建成 `K(Z,d)`，尤其检查对焦呼吸效应；
6. 另一台相机的完整标定；
7. 双目标定外参 `R、T`；
8. 验证双目外参是否随变焦或镜组运动发生显著变化。

因此，当前控制器可以使用本文件完成**相机0、约1.0 m、单目、变焦内参接入**；暂时不能把它当成双目系统或`0.8–1.3 m`全工作范围的最终标定。

## 10. 对接时需要队友确认

- 控制器读取的 `ZPOS、FPOS` 是否与本标定使用同一机械回零点和正方向；
- 每次移动是否采用一致的最终接近方向，以减少丝杆回差；
- 图像是否保持`1920 × 1080`，是否发生裁剪或缩放；
- 使用的是原始畸变图像、去畸变图像还是双目校正后图像；
- IBVS交互矩阵中的 `fₓ、fᵧ、cₓ、cᵧ` 是否按当前实时ZPOS更新；
- `Z=2200、2400`的主点和畸变警告是否会影响当前控制实现；
- 在双目外参 `R、T` 尚未标定前，不得把现有数据解释为完整双目标定。
